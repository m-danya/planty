HaelDB
------

- UI Sounds: https://opengameart.org/content/ui-sounds-0

The source pack uses numeric filenames and describes the collection as UI
accept, notification, attention, and error sounds. A subset of the numeric
variants is included for auditioning; the explicitly named "Wrong Error"
file is omitted.
Files: haeldb_ui_2.ogg, haeldb_ui_5.ogg, haeldb_ui_8.ogg.
